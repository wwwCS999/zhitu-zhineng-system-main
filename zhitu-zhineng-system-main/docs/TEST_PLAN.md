# 测试方案

## 数据
- `data/sample-jd-120.csv`：覆盖人工智能、大数据、Java、物联网、云原生、智能系统等 120 条岗位 JD。
- `data/gold-extractions.json`：岗位名称、职责、必备技能、加分技能、场景金标准。
- `data/test-cases.json`：JD 解析、简历解析、匹配、幻觉审核测试用例。

## 指标
- JD 解析：技能实体 Precision / Recall / F1，目标 ≥ 0.90。
- 简历解析：技能实体 F1，目标 ≥ 0.90。
- 匹配：与专家标签比较 Accuracy / MAE，目标 Accuracy ≥ 0.90。
- 新岗位发现：候选纯度、跨来源支持率、人工通过率。
- 图谱可信性：证据覆盖率、低置信关系占比、幻觉拦截率。

## 自动化
后端包含规则引擎、分数引擎、清洗和图谱服务单元测试；`mvn test` 生成 JaCoCo 报告，最低行覆盖率阈值 60%。


## 重复数据验证
- 导入阶段必须保留 120 条岗位记录。
- 完全重复和近重复内容标记 `duplicate_group` / `DUPLICATE_REVIEW`。
- 重复证据支持分和关系置信度增量低于独立原始证据，避免模板抄袭放大技能频率。
