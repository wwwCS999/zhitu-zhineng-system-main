# 赛题要求—系统功能映射

| 赛题要求 | 系统模块 | 关键实现 |
|---|---|---|
| 多源数据采集与治理 | 数据治理智能体 | CSV/PDF/Word/HTML/文本解析、清洗、哈希去重、近重复模板、时滞和质量评分 |
| 新岗位发现与定义 | 岗位洞察智能体 | 标题与技能组合聚类、增长/新颖度评分、职责/必备/加分技能/场景定义、人工发布 |
| 既有岗位动态更新 | 能力图谱与演化智能体 | 新增/弱化/修改事件、周期、说明、证据数、可信度、审核后更新 |
| 技能点级全景图谱 + 能力动态演化 | 能力图谱与演化智能体 | 岗位—技能关系、技术栈与等级过滤、力导向交互、证据关系，以及技能新增/弱化/修改演化 |
| 简历解析 ≥90% | 画像匹配智能体 | Tika 文档解析、技能本体抽取、项目/学历/经验提取、离线金标准复测 |
| 多维匹配与差距分析 | 画像匹配智能体 | 技能/项目/技术栈/等级/学历五维评分、已匹配/缺失技能、解释与建议 |
| 学习路径规划 | 学习规划智能体 | 前置依赖拓扑、阶段目标、周数/工时、交付物与考核方式 |
| 幻觉防控 | 可信审核智能体 | 多源支持、证据绑定、可信度/风险、低证据拦截、人工通过/修改/驳回、审计日志 |
| 至少100条JD | 测试数据 | 120条多技术栈 JD、金标准、测试用例、新岗位与既有岗位样例 |
| Docker 与部署说明 | 工程化 | Docker Compose、MySQL、Redis、后端、Nginx 前端、README 与 API 文档 |
| 单元测试覆盖率≥60% | 自动测试 | JUnit 单元测试与 JaCoCo 60% 阈值；需在可联网 Maven 环境执行最终覆盖率报告 |
