# 系统架构

## 六智能体协同
1. **数据治理智能体**：网页/CSV/PDF/Word/文本采集，清洗、哈希去重、近重复模板检测、时滞评分、技能标准化、质量分级。重复 JD 不直接删除，而是保留来源记录、绑定重复组并降低证据权重。
2. **岗位洞察智能体**：JD 结构化解析、新岗位聚类与定义、既有岗位技能新增/删除/修改分析。
3. **能力图谱与演化智能体**：岗位—技能—技术栈—层级—场景—资源图谱（技术栈/岗位等级视图切换），以及岗位能力的新增、弱化、修改动态演化。
4. **画像匹配智能体**：简历解析、技能画像、多维匹配、技能缺口与可解释评分。
5. **学习规划智能体**：按前置依赖、重要度、缺口和时间预算生成阶段化学习路径。
6. **可信审核智能体**：RAG 证据绑定、多源交叉验证、置信度、幻觉风险、人工审核、版本与审计。

## 闭环流程
数据采集 → 清洗与治理 → JD 解析 → 新岗位发现/岗位演化 → 可信审核 → 图谱发布 → 简历解析 → 匹配诊断 → 学习规划 → 用户反馈 → 下一轮演化。

## 可信机制
每个技能关系都保存证据数量、独立来源数、最近证据日期、支持率和置信度；单一来源、陈旧证据、重复模板和能力通胀会触发风险扣分。未经审核的高风险关系不进入正式图谱。
